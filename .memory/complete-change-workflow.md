自 2026-11-10 起，一项完整的、已验证的变更交付前，必须同步更新 `AGENTS.md` 中受影响的仓库架构、命令或约定，更新 `.memory/MEMORY.md` 索引与相关记忆文件中的当前状态；随后为该变更创建一次本地 Git 提交。除非用户明确要求，否则不得推送。

**Why:** 用户要求后续会话能准确理解项目演进，并让每项完整变更都有可追溯、可回退的本地提交。

**How to apply:** 提交前检查工作区，只暂存属于该变更的文件，避免混入用户已有改动。`.memory/` 当前被忽略，应按已跟踪路径或明确的单个文件强制暂存，不要强制加入整个目录。交付消息包含提交哈希与实际运行的验证。研究、未批准的设计、阻塞或半成品不算完整变更，不为其制造完成提交。
